# Loy Family Lights — Christmas Cinematic Estate v5

Static website for loyfamilylights.com, adapted from the Christmas Cinematic Estate v5 design and ready for Cloudflare Pages + GitHub.

## Cloudflare Pages
- Framework preset: None
- Build command: leave blank
- Build output directory: `/`
- Production branch: `main`

## Main pages
- `index.html` — Christmas Estate home
- `schedule.html` — nightly hours + countdown
- `watch.html` — YouTube live + request links
- `visit.html` — visitor etiquette and safety

## Assets
- `assets/css/styles.css` — Christmas Cinematic Estate v5 visual system + static-site adaptation
- `assets/js/app.js` — countdown, mobile navigation, and reactive fog

## External links
- Song requests: https://show.loyfamilylights.com/
- YouTube live: https://www.youtube.com/@loyfamilylights/live

## Show configuration
The countdown settings remain in `assets/js/app.js`. Current default start time is 9:00 PM, with end times of 10:00 PM Sunday–Thursday and 11:00 PM Friday–Saturday.
